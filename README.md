# 🩺 Chronic Kidney Disease (CKD) Prediction using AI

This repository provides a machine learning framework for early prediction of Chronic Kidney Disease (CKD) using clinical data. The project uses real-world patient data collected in Pakistan and implements interpretable AI techniques such as SHAP and LIME to improve model transparency and trustworthiness.

---

## 📌 Project Objectives

- Predict CKD stages or presence using clinical features (e.g., hemoglobin, WBC, RBC, etc.)
- Apply machine learning algorithms (Random Forest, XGBoost, CatBoost, etc.)
- Implement deep learning models and AutoML frameworks
- Provide model interpretability with SHAP & LIME
- Improve early diagnosis for better treatment planning

---

## 🧠 Technologies Used

- Python 3.10+
- Scikit-learn
- XGBoost, CatBoost, LightGBM
- Keras / TensorFlow
- SHAP, LIME (Explainable AI)
- Pandas, NumPy, Matplotlib, Seaborn
- Jupyter Notebooks
